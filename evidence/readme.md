# Evidence

This directory contains screenshots collected during the assessment as supporting evidence for the activities, findings, and attack path documented in this project.

The screenshots are organized under the `screenshots/` directory and provide visual evidence of key stages of the assessment, including reconnaissance, exploitation, initial access, local enumeration, privilege escalation, and verification of the assessment objectives.

The contents of `local.txt` and `proof.txt` are not shown in the screenshots to preserve the integrity of the original capstone assessment.
